EtherGate modules

Three symbols and one shared library for an Enttec DIN EtherGate. The processor sends Art-Net. The gateway turns that into DMX on two ports.

Start here

Drop one Controller for each physical gateway, one Channel for the loads on a port, and one Preset for each preset you want to save and recall. All three must use the same controller number to talk to the same gateway.

  1. Keep EtherGate_v1.clz in the same folder as these modules. The program will not link without it.
  2. On the gateway, set each port you drive to DMX Out (RDM is fine) and protocol Art-Net. Give the node a static address, or a DHCP reservation that never moves.
  3. Add EtherGate Controller v1.0. Set IP_Address and Controller (1 through 8). Set Port_1_Universe and Port_2_Universe to the universes configured on the node. Hold Connect high.
  4. Add EtherGate Channel v1.0. Set Port and the same Controller. Expand a row for each load, set that row's Channel_ID, and drive Channel from a fader.
  5. Add EtherGate Preset v1.0 symbols for the presets. Same Controller. A short press of Preset recalls. Holding it saves, then Preset_FB blinks.
Press F1 on any of these symbols in SIMPL Windows to open this page. Leave EtherGate v1.html next to the .usp files.

The three symbols

Controller

Owns the socket for one gateway. Streams Art-Net while connected and reports the node name and port mode.

Channel

Up to 64 DMX addresses on one port. Each row is percent. Full scale, 65535, is DMX 255.

Preset

One preset for that gateway. A short press recalls. A hold saves and blinks the button. The gateway itself stores nothing.

The DIN EtherGate is a two-universe Ethernet-to-DMX gateway. It does not hold scenes, cues, or shows. Those live in the Crestron program. Up to eight gateways can run at once. Each one is a numbered slot.

Which gateway

Every symbol has a Controller parameter, with a list from Controller 1 to Controller 8. The default is 1. On Channel it sits above the load rows.

Every override input uses its parameter until a value arrives on that input. After the first value, that input is in charge, and 0 is a real value. An input left unwired never takes over. Use one Controller symbol per slot. Two Controller symbols on the same number will fight over the address.

Same number, same gateway. A Channel or Preset only affects the gateway selected on that symbol. A preset saved on Controller 1 does not include channels that are pointed at Controller 2.

Controller

EtherGate Controller v1.0 opens the session and keeps Art-Net flowing. Hold Connect high to connect. Pulse Disconnect to stop the stream and close the session.

SignalKindWhat it does
ConnectDigital inHigh connects and starts the Art-Net stream.
DisconnectDigital inHigh stops the stream.
Connected_FBDigital outHigh only after the gateway accepts a connection on port 80. Stays low, with status No response, when that address does not answer. Art-Net starts after this goes high.
IP_AddressParameterStatic address of the gateway. Default 0.0.0.0, which refuses to connect.
IP_Address_Override$Serial inIgnored until a string arrives. After that, this serial is the address, even if a later string is empty. A change while connected opens the new address.
Status$Serial outShort reason: address not set, connecting, no response, online, disconnected.
Node_Name$Serial outName from the gateway, after a config poll parses.
Firmware$Serial outFirmware string from that same poll, when the body contains one.
Port_1_Mode$Serial outPoll result for the node. poll pending until the first body, then a short description or unparsed.
Port_2_Mode$Serial outSame text as port 1 until a future parser can split the two ports.
Port_1_UniverseParameterArt-Net universe sent to port 1. Default 0. Range 0–32767.
Port_1_Universe_OverrideAnalog inIgnored until a value arrives. After that, this analog is the universe, and 0 is universe 0.
Port_2_UniverseParameterArt-Net universe sent to port 2. Default 1.
Port_2_Universe_OverrideAnalog inSame rule as port 1.
ControllerParameterSlot 1–8. Bottom parameter.
Controller_OverrideAnalog inIgnored until a value arrives. After that, 1–8 selects that slot.
PresetAnalog inRecalls a preset saved on this slot. 1–64 selects that preset and recalls it as a cut. 0 does nothing. An empty preset does not move levels. Return the analog to 0 before sending the same number again.

While connected, the library sends a full 512-channel Art-Net packet for each port about 20 times a second. The gateway refreshes the DMX jacks on its own. If the stream stops, fixtures drop out.

A separate poll reads the node’s web page so the name and mode strings can fill in. Lighting does not wait on that poll. The published command set is the DIN EtherGate (SKU 71030) API. The MK2 (SKU 71031) has a user manual and no separate API document, so the first poll from a live unit is what confirms the body format.

Channel

EtherGate Channel v1.0 is a run of loads on one port. It opens with one row. Expand that row for each additional load, up to 64.

SignalKindWhat it does
PortParameterPort 1 or Port 2. Default Port 1. Shared by every row.
ControllerParameterWhich gateway. Sits above the load rows.
Controller_OverrideAnalog inIgnored until a value arrives. After that, 1–8 selects that slot. Same row as Controller.
ChannelAnalog inPercent for this row. 0 is off. 65535 is DMX 255. Expand for another load.
Channel_IDParameterDMX address 1–512 for this row. Default 1. Same row as Channel and Channel_FB.
Channel_FBAnalog outThe live percent for this row, including while a preset is fading. Same row as Channel.

A change on Channel writes that row's Channel_ID. The next Art-Net packet carries it. This symbol only wakes for its own port and addresses. A move on another load does not run these rows.

Writing Channel while a fade is running on that address cancels the fade for that address only. The newest command wins.

Preset

EtherGate Preset v1.0 holds the presets for the Channel rows on the same controller slot. The gateway does not store them. This module does.

Eight rows follow Hold_Time and Confirmation_Time. Each of those rows is Preset, Preset_No, and Preset_FB together. A blank row follows those buttons. Preset_Trigger is the next row, and Preset_Save is the row under that. A blank row follows, then Fade_Time with Fade_Time_Override, Channels with Channels_Override$, another blank row, and Controller with Controller_Override.

SignalKindWhat it does
PresetDigital inThe button for this row. Release before Hold_Time recalls. Hold for Hold_Time saves. Still holding at 10 seconds erases. Same row as Preset_No and Preset_FB.
Preset_NoParameterWhich stored preset this row uses. 0 is off. 1–64 selects that preset. Default 0. Same row as Preset and Preset_FB.
Preset_FBDigital outHigh while this row's button is held. A save blinks it, then it stays high when every stored channel in this symbol's list still matches. Same row as Preset.
Preset_TriggerAnalog inRecalls any stored preset 1–64, using this symbol's fade and channel list. 0 does nothing. It does not save or erase. Return the analog to 0 before sending the same number again.
Preset_SaveAnalog inSaves any stored preset 1–64, using this symbol's channel list. 0 does nothing. It does not recall or erase. Return the analog to 0 before sending the same number again. A value present at startup waits until the analog changes.
Hold_TimeParameterHow long a press must be held to save. Default 2.5s. Range 0.5s to 9.0s. Shared by every row.
Confirmation_TimeParameterTotal length of the save blink. Default 1.2s. Choices are 0.6s, 1.2s, 1.8s, 2.4s, and 3.0s. The blink is off, on, off, on, off, on across that time.
Fade_TimeParameterSeconds, typed on the symbol. Default 0, a cut. 0.5s is half a second. Maximum 600.0s.
Fade_Time_OverrideAnalog inTenths of a second. Ignored until a value arrives. After that, this analog is the fade, and 0 is a cut. 5 is 0.5 seconds. 50 is 5.0 seconds.
ChannelsParameterComma-separated channels this symbol controls. Empty means every defined channel. 12 is channel 12 on either port. 1:12 is port 1 channel 12, and 2:12 is port 2. 255 characters.
Channels_Override$Serial inIgnored until a string arrives. After that, this serial is the list, and an empty serial means every defined channel.
ControllerParameterWhich gateway. Bottom parameter.
Controller_OverrideAnalog inIgnored until a value arrives. After that, 1–8 selects that slot.

How a preset learns its channels

Each Channel symbol registers itself with the core when the program starts, under its port and DMX address, on the slot it is pointed at. Channels chooses which of those addresses this symbol controls.

An empty list saves every defined address and replaces the preset. A list writes only those addresses and leaves any other stored addresses in place. Recall moves only stored addresses that are in the list. Holding the button for 10 seconds removes the listed addresses; with an empty list, that hold clears the preset. An address with no Channel symbol is not written on save.

Two Channel symbols on the same port and address count once. A Channel symbol you add after a save is not in that preset until you save again. A symbol you delete stays in a preset that was already saved, and recall will still drive that DMX address.

Presets are written to \user\EtherGate\slotN.presets on the processor. They come back after a reboot. If the file cannot be written, the Controller Status$ reports that the preset did not persist. The live levels still run.

Recall only touches stored addresses that are in this symbol's list. Other DMX channels stay where they are.

Levels and fades

Channel levels are Crestron analog percent.

AnalogDMX
00
32768about 50%
65535255, full

A fade steps from the live level to the stored level. Channel_FB on each member channel follows the ramp, so a gauge moves during the recall. Time is in tenths of a second on the Preset symbol. Zero is a cut. The core will not fade longer than 10 minutes.

Preset_FB, once the press is released and any save blink has finished, compares the live DMX value with the value that was stored. It is high only when the preset was saved and every stored channel in this symbol's list still matches. Moving one of those channels drops that feedback. A channel named in the list but never saved does not hold the feedback low. After the faders sit still, a preset that happens to match will light again.

The gateway

Before the Controller can drive fixtures, the node has to be commissioned for output.

  • Address: static, or a reservation. Type that address on IP_Address. The module does not search the network.
  • Port direction: DMX Out. A port left as an input will not emit the levels you send.
  • Protocol: Art-Net. These modules transmit Art-Net only.
  • Universe: the number on the node must match Port_1_Universe and Port_2_Universe. Factory MK2 values are universe 0 on port 1 and universe 1 on port 2.
These modules do not change the node’s IP, DHCP, universe, protocol, or refresh rate, and they do not factory-reset or reboot it. Do that in the node’s web page.

Art-Net is unicast to the gateway on UDP port 6454. The HTTP poll uses TCP port 80 and is only for the name, firmware, and mode text.

Target processor is 4-Series. Compile the SIMPL+ modules with \target series4 after the .clz is in place.
