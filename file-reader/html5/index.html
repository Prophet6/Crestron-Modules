Detected lights after a read. It is not the format you are about to write. -1 is undetected. -2 is an integrity failure.

Auto-create

Set_Default_Values

Held high, a missing file pulses Set_Default_Values, waits Default Wait Time, then writes. An existing file is read and is not overwritten. The values already in the editor are what get written.

Backup

No backup

With backup enabled, a write stores name.ext.bak beside the file. With history also enabled, the previous backup is archived as .bak.yyyyMMdd.gz instead of being overwritten.

Encrypt

Not encrypted

A write with Encrypt high and no key fails. A read of an encrypted file fails without the same key.

Set in SIMPL

  • File Location is the folder string from the user-module list: \nvram\, \user\, \html\, \rm\, or \rm2\. Parameter on this page uses that string. The extension is still appended.
  • Filename is used while the name override is empty.
  • Format is used while the Format analog is outside 1 through 6.
  • Default Wait Time is the pause after Set_Default_Values. Default 0.25s.

The edit column is sent to the module. The file column is what a read or a successful write put on the outputs. Read does not copy the file back into the edits.
