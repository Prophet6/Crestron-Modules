File Reader v3.3.0

One user module and one shared library that store and restore digital, analog, and serial signals in a file on the processor.

Start here

File Reader v3.3.0 writes the signals on the symbol into a file, and reads that file back onto the outputs. Reads detect the format. Writes use the format you select. A successful write also copies the inputs onto the outputs. The folder is a 4-Series path. Compact flash is not offered.

User module

File Reader v3.3.0 is the symbol you drop in SIMPL Windows. F1 on that symbol opens this page. The groups, top to bottom, are File_Location, File_Info, Format, Digital, Analog, and Serial.

SIMPL+ symbol

The paired SIMPL+ module can stay visible until it is inside this user module. Its F1 help is the comment inside the .usp. Copy-after-write, auto-create, and the folder override live there.

Library

Library FileReader_v3, source FileReader20261013.cs, class FileDataHandler. Keep FileReader_v3.clz next to the .usp. Assembly version 3.2.1.0. The archive name stays on the major version.

  1. Keep FileReader_v3.clz next to File Reader v3.3.0.usp. This package targets 4-Series only.
  2. Add File Reader v3.3.0. Set File Location, Filename with no extension, and Format. The format default is 4, JSON. The folder default is \nvram\.
  3. Expand the digital, analog, and serial pairs you need. The symbol ships with 64 of each type, and the arrays can be raised to 256.
  4. Drive the inputs, then pulse Write. On success the file is stored and every input is copied to the matching output. Digitals are driven as an explicit 0 or 1.
  5. Pulse Read to load a file. Detected_Format_FB and Operational_Feedback report what was found. Outputs stay where they were if the read fails.
  6. For startup, hold Auto_Create_File high and wire Set_Default_Values to the logic that drives the default inputs. A missing file is created. An existing file is read and is not overwritten.
Press F1 on the File Reader v3.3.0 user module to open this page. Leave File Reader v3.3.0 Technical Manual.html next to the .umc.
Path. The file is the chosen folder plus Filename, or File_Name when that string is not empty, plus the extension for the active format. Do not put the extension in the name. The folder string includes its trailing separator. No extra slash is inserted. With Match_Partial high, that name is a fragment. config and JSON can select Boardroom1S25_config.json in the same folder. The comparison ignores case. Several matches use the first name alphabetically. No match uses the fragment as the whole file name, so auto-create can write config.json. Directory names on a 4-Series processor are case-sensitive. Use the lowercase paths in the File Location list.

Formats

The Format parameter chooses the file written. The Format analog replaces that parameter when its value is 1 through 6. Format_Text through Format_Binary set that analog to 1 through 6. Reads ignore the selection and detect the format. Detected_Format_FB is across from the Format analog. Format_Text_FB through Format_Binary_FB follow the detected code.

CodeFormatExtension
1Text.txt
2CSV.csv
3XML.xml
4JSON.json (default)
5INI.ini
6Binary.bin

After a read, Detected_Format_FB is 1 through 6, -1 when the format is undetected or the read errors, or -2 when a non-JSON integrity check fails. A SIMPL analog is 16-bit, so -1 and -2 arrive as 65535 and 65534. A write does not change Detected_Format_FB.

JSON

JSON may come from this module or from another tool. The reader looks for digitals, analogs, and serials arrays, at the top level or nested under data or signalData. Names are case-insensitive. Arrays may be shorter than 64. Missing slots stay 0 or empty. Digital elements may be 0 or 1, integers, or JSON booleans. An optional crc32 field is ignored for pass or fail.

{
  "digitals": [0, 1, 0, 1],
  "analogs": [8, 16, 32, 64],
  "serials": ["Room A", "Scene 1", "", ""]
}

A write from this module stores a full 64-element set and may include crc32. Readers do not require it.

Auto-create

Hold Auto_Create_File high to replace an external routine that wrote defaults when the file was missing and read the file when it already existed.

  1. Hold Auto_Create_File high.
  2. Wire Set_Default_Values to logic that drives the digital, analog, and serial inputs with the default configuration.
  3. On startup, or when the effective path changes, a missing file pulses Set_Default_Values, waits Default Wait Time, writes, then copies the inputs to the outputs.
  4. An existing file is read onto the outputs. Auto-create does not overwrite it.
  5. One automatic action runs for a path. Changing the folder, the name, the format, or Match_Partial allows another.

Busy_FB stays high through that sequence, including the settle wait and the write or read. An override of 1 through 5 still runs when the File Location parameter string is empty.

Backup and encryption

With Enable_Backup high, a write stores name.ext.bak in the same folder. With Enable_Backup_History also high, the previous backup is archived as .bak.yyyyMMdd.gz instead of being overwritten.

  • Pulse Restore_Backup to put the .bak back.
  • Pulse Delete_Backup to remove the .bak. Backup_Exists_FB follows the result.
  • Pulse Delete to remove the main file. The backup file is left in place.

Set Encrypt high and provide Encryption_Key before a write that should be encrypted. On read, the header sets Encrypted_FB. Provide the same key.

A write with Encrypt high and no key fails. A read of an encrypted file with no key fails. The key has to match the key that wrote the file.

Non-JSON formats can fail the checksum. Detected_Format_FB becomes -2 and Operational_Feedback names the format. JSON does not fail the read because crc32 is missing or different.

Examples

JSON configuration in User

  1. Set Format to 4. Set File Location to \user\ and Filename to config. Format 4 appends .json, so the file is \user\config.json.
  2. Connect Analog_Input_1 to the volume level.
  3. Pulse Write. The outputs copy the inputs. Exists_FB goes high. File_Name_FB shows config.json.
  4. Pulse Read. Detected_Format_FB is 4 and the outputs load.

Pick the folder from a button

  1. Leave File Location at \nvram\. Pulse File_Location_User_Folder. The File_Location analog becomes 2, so the file opens under \user\ instead of the parameter.
  2. Set the File_Location analog to 0 to return to the parameter.

Partial name

Hold Match_Partial high, set File_Name to config, and use format 4. The module opens the first .json file in that folder whose name contains config. File_Name_FB shows the full name, including the extension.
